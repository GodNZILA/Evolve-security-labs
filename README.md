# Evolve Security Labs

This is my lab notebook.

I'm changing careers into cybersecurity, and I learn by doing. Every time I finish a hands-on lab in the **Evolve Security Academy** bootcamp, I write down what it was really about, how I worked through it, and what I walked away understanding. Not a copy of the course — my own notes, in my own words.

Each folder is a module. Each file is one lab: what the goal was, the tools I used, what I did, what I learned, and how I'd defend against it. If you want to see how I think and how I'm progressing, open any of them and read.

I'll keep adding to this as I go — some labs are already done and waiting to be written up, more are coming.
